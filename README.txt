IMPORTANT — HOW TO TEST AND DEPLOY
1. Extract this ZIP fully. Do not preview index.html from inside the ZIP or from the Android Files content:// preview. That preview can fail to load neighbouring CSS/JS files.
2. For GitHub Pages, upload the CONTENTS of this folder to the root of your GitHub repository (not an extra enclosing folder).
3. Make sure index.html, shop.html, cart.html, bespoke.html, css/ and js/ are all at the repository root level as shown below.
4. In GitHub, open Settings → Pages and publish from your chosen branch/root.
5. Open the published https://<username>.github.io/<repository>/ address in Chrome and refresh.

Expected structure:
index.html
shop.html
cart.html
bespoke.html
css/style.css
js/script.js
README.txt
